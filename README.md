# Agent Island · 0.1

Нативная панель macOS возле чёлки. Нажмите на полоску, чтобы раскрыть статусы. Значок в строке меню позволяет свернуть панель, включить демонстрацию и выйти. Демо всегда помечено и не записывает искусственные события в рабочие сеансы.

## Запуск

Требуются Apple Silicon, macOS 14+ и Xcode Command Line Tools.

```sh
xcode-select --install
./build.command
open "Agent Island.app"
```

Затем запустите `./connect.command` для подключения событий и `./connect-metrics.command` для лимитов Claude Code. Эти команды изменяют локальные настройки интеграций и сохраняют резервные копии.

- Codex в приложении и терминале: обнаружение локальных журналов плюс события hooks.
- Claude Code в терминале: локальные журналы плюс hooks.
- Claude в приложении, Code / Cowork: чтение обнаруженных локальных журналов. Изолированные или удалённые сеансы без локального журнала не видны.
- Обычный чат Claude: кнопка **Подключить** открывает доступность macOS. Разрешите Agent Island доступ в «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ». Определяется наличие кнопки остановки генерации в доступном окне, поэтому фоновые чаты и все состояния здесь не поддерживаются. Отсутствие кнопки не считается доказательством завершения.

Codex требует доверия новым hooks: откройте `/hooks` в Codex CLI и проверьте записи с `AgentIsland/monitor.py`. Пока доверие не выдано, чтение журналов продолжает работать, но ожидание разрешения может не определяться. Уже запущенным сеансам может понадобиться перезапуск для загрузки подключений. Автоматического подтверждения запросов агентов нет.

## Что означают статусы

**В работе** — получено событие работы. **Требует внимания** — получен запрос разрешения или уведомление ожидания. **Готово** — завершён ответ агента (не гарантия успешного выполнения всего проекта). **Нет сигнала** — нет подходящего события, сеанс недоступен либо активность устарела. При отсутствии событий работы в течение 10 минут статус становится неизвестным. Запросы уточнения определяются только если источник передал соответствующее событие.

Показываются до 30 сеансов за последние сутки; файлы ищутся среди обновлённых за три дня. Новые журналы обнаруживаются примерно за 15 секунд, изменения — за 3 секунды. Карточки кликабельны: Codex открывает задачу по ID, локальные сеансы Claude Desktop — по ссылке Cowork. Для терминального Claude приложение пытается найти единственное окно Terminal, iTerm или Ghostty с ID или названием чата в заголовке (нужен универсальный доступ). Если точный переход недоступен, открывается источник и показывается пояснение; выбор вкладки терминала не гарантируется.

## Приватность и ограничения

Нет сетевых запросов, API-ключей и платных API. Журналы обрабатываются локально; панель использует метаданные сеанса: идентификатор, источник, название, имя папки, время, статус и счётчики использования. Тексты сообщений не сохраняются панелью. Формат журналов не является стабильным API: после обновления Codex/Claude может понадобиться обновить адаптер.

Настройки hooks дополнены без удаления прежних подключений. Резервные копии находятся в `~/Library/Application Support/AgentIsland/backups`. `disconnect.command` удаляет только hooks Agent Island, сохраняя другие настройки. Для полного удаления затем выйдите из приложения, удалите его папку и при желании папку данных AgentIsland.

Сборка для Apple Silicon, macOS 14+. Используется `/usr/bin/python3`, доступный на проверенном Mac с инструментами разработчика. Для сборки нужен Swift / Xcode Command Line Tools; запустите `build.command`. Приложение имеет локальную подпись, не нотарифицировано для публичного распространения. Автозапуск не включён.

## Проверено

Сборка Swift, подпись приложения, запуск на macOS 15.6.1, свёрнутая и раскрытая панель, чтение реальных сеансов Codex Desktop / Claude CLI. Проверены переходы статусов, незавершённая строка журнала, отсутствие текстов запросов в файлах событий, сохранение существующих hooks и повторная установка без дублей. Обычный чат Claude с разрешением доступности и новый сеанс Claude Desktop пока не проверены в работе.

Документация: [Codex hooks](https://learn.chatgpt.com/docs/hooks), [Claude Code hooks](https://code.claude.com/docs/en/hooks).

## Время, токены и лимиты

В карточках «Запрос» — время с начала текущего пользовательского запроса, включая ожидание, а не возраст последнего события. Завершённые запросы показывают фиксированную длительность. «Токены сеанса» — суммарный обработанный вход и выход за локальный сеанс; кэш входит во вход и повторно учитывается при повторном чтении. Это не размер контекстного окна и не число токенов, списанных из подписки. Записи Claude с одинаковым ID ответа не суммируются повторно. Субагентские журналы отдельно не включены.

Лимиты подписки показываются в процентах с отметкой времени снимка. Codex берётся из последних локальных событий token_count, Claude — из документированного поля rate_limits строки состояния Claude Code. Для подключения Claude используйте connect-metrics.command; прежняя строка состояния, если она была, вызывается после сохранения метаданных. disconnect.command восстанавливает её. Данные обновляются при активности агентов; после времени сброса старый процент не выдаётся за актуальный.

При пересечении очередных 10% расхода показывается уведомление на 7 секунд. Первый снимок становится начальной точкой и не вызывает старые уведомления. Пороги сохраняются между перезапусками отдельно для каждого лимита и периода сброса. Если свежий снимок перескочил несколько порогов, показывается один актуальный остаток. Нет фиксированного «остатка токенов» подписки: проценты не пересчитываются в токены.

Уведомления ожидания ответа, готовности и лимитов автоматически скрываются через 7 секунд. Завершения старых сеансов при запуске не вызывают уведомлений. Клик вне открытой панели сворачивает её.

## Настройки

Шестерёнка открывает три вкладки. «Уведомления»: общий переключатель, ожидание ответа, готовность, ошибки, пороги лимита, выбор Codex/Claude, звук и автоскрытие (3–30 секунд или вручную). «Внешний вид»: сторона чёлки, размер и наложение логотипов, анимация и скорость, ширина панели, скругления, тень и плавное раскрытие. «Панель»: видимость сеансов, времени, токенов и лимитов, число сеансов, состояние подключения обычного чата Claude и закрытие по внешнему клику. Для каждого источника доступны режимы «Всегда показывать», «Скрывать без связи», «Скрывать без активных задач» и «Всегда скрывать». Значения сохраняются локально и применяются без перезапуска. Звук по умолчанию выключен. Уменьшение движения в macOS отключает анимацию независимо от переключателей приложения.

## Демонстрация и интерфейс

В настройках уведомлений нажмите «Демо». Сценарий показывает раскрытие и сворачивание, ожидание действия, завершение, ошибку и остаток лимита; в конце — 12 искусственных чатов с прокруткой. После демо восстанавливаются реальные данные.

Сеансы показаны отдельными карточками. Подсказки при наведении объясняют иконки токенов; длинный список имеет постоянно видимую полосу прокрутки. Логотип бренда подпрыгивает при ожидании действия.
