# Agent Island · 0.1.2

Нативная панель macOS возле чёлки. Нажмите на полоску, чтобы раскрыть статусы. Значок в строке меню позволяет свернуть панель, открыть настройки и выйти. Демонстрация запускается в настройках уведомлений. Демо всегда помечено и не записывает искусственные события в рабочие сеансы.

## Установка — шаг за шагом

Для Mac с чипом **Apple M1 или новее** и **macOS 14 или новее**. Проверить свой Mac: меню ** → Об этом Mac**. Сборка для Intel пока не опубликована.

### 1. Установите необходимые инструменты

Нажмите **⌘ + пробел**, напишите **Терминал** и нажмите Enter. Скопируйте в открывшееся окно команду и нажмите Enter:

```sh
xcode-select --install
```

В появившемся окне нажмите **Установить** и дождитесь завершения. Если написано, что инструменты уже установлены, ничего делать не нужно. Они содержат Python, который нужен приложению для чтения статусов.

### 2. Скачайте готовое приложение

Нажмите **[Скачать Agent Island 0.1.0 для Mac](https://github.com/youngpirate32/agent-island/releases/download/v0.1.0/Agent-Island-0.1.0-arm64.zip)**.

Откройте папку **Загрузки**, дважды нажмите на скачанный ZIP и перетащите появившийся **Agent Island.app** в папку **Программы**. Собирать приложение самостоятельно не требуется.

### 3. Запустите приложение

Откройте **Программы → Agent Island**. Остров появится у верхнего края экрана возле чёлки. Нажмите на него, чтобы раскрыть панель.

Если macOS не разрешает открыть приложение: после попытки запуска откройте **Системные настройки → Конфиденциальность и безопасность**, найдите сообщение об Agent Island и нажмите **Всё равно открыть**, затем подтвердите запуск. Это локально подписанная сборка без нотарификации Apple.

### 4. Подключите события и лимиты

**[Скачайте файлы подключения](https://github.com/youngpirate32/agent-island/archive/refs/tags/v0.1.0.zip)** и распакуйте ZIP. Откройте получившуюся папку `agent-island-0.1.0`.

По очереди дважды нажмите:

1. **connect.command** — подключает события Codex и Claude Code.
2. **connect-metrics.command** — подключает получение лимитов Claude Code.

Откроются окна Терминала. Дождитесь завершения каждой команды. Файлы `.command` должны оставаться рядом с папкой **Resources**: не переносите их отдельно. Эти команды дополняют локальные настройки агентов и сохраняют резервные копии. Для готовой сборки запускать **build.command** не нужно.

Если macOS блокирует файл подключения, используйте **Конфиденциальность и безопасность → Всё равно открыть** после попытки его запуска, как на предыдущем шаге.

Перезапустите сеансы Codex и Claude Code, чтобы они подхватили подключения. В Codex CLI откройте `/hooks` и подтвердите доверие записям Agent Island, если оно запрашивается. Сбор лимитов Claude работает без добавления нашей видимой строки в терминал.

### 5. Разрешите универсальный доступ

Раскройте остров и нажмите **Универсальный доступ**. В настройках macOS включите **Agent Island**. Если его нет в списке, нажмите **+** и выберите **Программы → Agent Island.app**.

Разрешение нужно для переключения окон терминала и определения генерации в обычном чате Claude. Для чтения локальных журналов оно не требуется. После выдачи доступа кнопка в острове исчезнет. Её видимость можно изменить в **шестерёнка → Панель → Универсальный доступ**.

### 6. Настройте автозапуск

Нажмите **шестерёнку → Основные → Запускать при входе в macOS**. Чтобы отключить автозапуск, выключите тот же переключатель. **Выйти из Agent Island** закрывает приложение сейчас, но не отключает будущий автозапуск.

### 7. Проверьте работу

Откройте **шестерёнка → Уведомления → Демо**. Приложение покажет анимации, разные статусы, уведомления и список из 12 примерных чатов, затем вернётся к настоящим данным.

После этого запустите задачу в Codex или Claude Code. Новый сеанс обычно обнаруживается в течение 15 секунд. Наведите указатель на иконку счётчика токенов, чтобы увидеть пояснение.

### Если что-то не появилось

- **Нет неактивных приложений:** по умолчанию они скрыты. В **Настройки → Панель → Видимость источников** выберите **Всегда показывать** для нужного источника.
- **Вместо лимита прочерк:** запустите задачу в соответствующем агенте; данные приходят при его активности. Для Claude Code проверьте, что выполнен шаг 4.
- **Доступ включён, но приложение его не видит:** завершите Agent Island, удалите его запись из списка универсального доступа кнопкой **−**, добавьте текущий файл из **Программ** кнопкой **+**, включите и запустите приложение снова. После самостоятельной пересборки локальная подпись меняется, и разрешение может потребоваться заново.
- **Не открывается нужная вкладка терминала:** доступность названий зависит от терминала. Название сеанса должно быть уникальным; точный переход поддерживается не во всех случаях.

## Сборка из исходников (необязательно)

Если вы скачали готовое приложение, этот раздел можно пропустить. Для сборки нужны Xcode Command Line Tools. В папке исходников запустите `build.command`, затем откройте созданный **Agent Island.app**.

## Источники данных

- Codex в приложении и терминале: обнаружение локальных журналов плюс события hooks.
- Claude Code в терминале: локальные журналы плюс hooks.
- Claude в приложении, Code / Cowork: чтение обнаруженных локальных журналов. Изолированные или удалённые сеансы без локального журнала не видны.
- Обычный чат Claude: кнопка **Подключить** открывает доступность macOS. Разрешите Agent Island доступ в «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ». Определяется наличие кнопки остановки генерации в доступном окне, поэтому фоновые чаты и все состояния здесь не поддерживаются. Отсутствие кнопки не считается доказательством завершения.

Codex требует доверия новым hooks: откройте `/hooks` в Codex CLI и проверьте записи с `AgentIsland/monitor.py`. Пока доверие не выдано, чтение журналов продолжает работать, но ожидание разрешения может не определяться. Уже запущенным сеансам может понадобиться перезапуск для загрузки подключений. Автоматического подтверждения запросов агентов нет.

## Что означают статусы

**В работе** — получено событие работы. **Требует внимания** — получен запрос разрешения или уведомление ожидания. **Готово** — завершён ответ агента (не гарантия успешного выполнения всего проекта). **Нет сигнала** — нет подходящего события, сеанс недоступен либо активность устарела. При отсутствии событий работы в течение 10 минут статус становится неизвестным. Запросы уточнения определяются только если источник передал соответствующее событие.

Показываются до 30 сеансов за последние сутки; файлы ищутся среди обновлённых за три дня. Новые журналы обнаруживаются примерно за 15 секунд, изменения — за 3 секунды. Карточки кликабельны: Codex открывает задачу по ID, локальные сеансы Claude Desktop — по ссылке Cowork. Для терминального Claude приложение пытается найти единственное окно Terminal, iTerm или Ghostty с ID или названием чата в заголовке (нужен универсальный доступ). Поиск также проверяет вкладки и меню окон. Если точный переход недоступен или найдено несколько совпадений, панель не показывает диагностические сообщения о переходах.

## Приватность и ограничения

Нет сетевых запросов, API-ключей и платных API. Журналы обрабатываются локально; панель использует метаданные сеанса: идентификатор, источник, название, имя папки, время, статус и счётчики использования. Тексты сообщений не сохраняются панелью. Формат журналов не является стабильным API: после обновления Codex/Claude может понадобиться обновить адаптер.

Настройки hooks дополнены без удаления прежних подключений. Резервные копии находятся в `~/Library/Application Support/AgentIsland/backups`. `disconnect.command` удаляет только hooks Agent Island, сохраняя другие настройки. Для полного удаления затем выйдите из приложения, удалите его папку и при желании папку данных AgentIsland.

Сборка для Apple Silicon, macOS 14+. Используется `/usr/bin/python3`, доступный на проверенном Mac с инструментами разработчика. Для сборки нужен Swift / Xcode Command Line Tools; запустите `build.command`. Приложение имеет локальную подпись, не нотарифицировано для публичного распространения. Автозапуск по умолчанию выключен; его можно включить или отключить в настройках → «Основные». Там же находится кнопка выхода.

## Проверено

Сборка Swift, подпись приложения, запуск на macOS 15.6.1, свёрнутая и раскрытая панель, чтение реальных сеансов Codex Desktop / Claude CLI. Проверены переходы статусов, незавершённая строка журнала, отсутствие текстов запросов в файлах событий, сохранение существующих hooks и повторная установка без дублей. Обычный чат Claude с разрешением доступности и новый сеанс Claude Desktop пока не проверены в работе.

Документация: [Codex hooks](https://learn.chatgpt.com/docs/hooks), [Claude Code hooks](https://code.claude.com/docs/en/hooks).

## Время, токены и лимиты

В карточках «Запрос» — время с начала текущего пользовательского запроса, включая ожидание, а не возраст последнего события. Завершённые запросы показывают фиксированную длительность. «Токены сеанса» — суммарный обработанный вход и выход за локальный сеанс; кэш входит во вход и повторно учитывается при повторном чтении. Это не размер контекстного окна и не число токенов, списанных из подписки. Записи Claude с одинаковым ID ответа не суммируются повторно. Субагентские журналы отдельно не включены.

Лимиты подписки показываются в процентах с отметкой времени снимка. Codex берётся из последних локальных событий token_count, Claude — из документированного поля rate_limits строки состояния Claude Code. Для подключения Claude используйте connect-metrics.command; прежняя строка состояния, если она была, вызывается после сохранения метаданных. disconnect.command восстанавливает её. Данные обновляются при активности агентов; после времени сброса старый процент не выдаётся за актуальный.

При снижении остатка уведомления показываются на 90%, 80%, 70%, 60%, 50%, 40%, 30%, затем каждые 5%: 25%, 20%, 15%, 10%, 5% и 0%. Остаток 25% и ниже жёлтый, 10% и ниже красный. По умолчанию уведомление видно 7 секунд. Первый снимок становится начальной точкой и не вызывает старые уведомления. Пороги сохраняются между перезапусками отдельно для каждого лимита и периода сброса. Если свежий снимок перескочил несколько порогов, показывается один актуальный остаток. Нет фиксированного «остатка токенов» подписки: проценты не пересчитываются в токены.

Уведомления ожидания ответа, готовности и лимитов автоматически скрываются через 7 секунд. Завершения старых сеансов при запуске не вызывают уведомлений. Клик вне открытой панели сворачивает её.

## Настройки

Шестерёнка открывает четыре вкладки. «Основные»: включение и отключение автозапуска при входе в macOS, выход из приложения. «Уведомления»: общий переключатель, ожидание ответа, готовность, ошибки, пороги лимита, выбор Codex/Claude, звук и автоскрытие (3–30 секунд или вручную). «Внешний вид»: сторона чёлки, размер и наложение логотипов, анимация и скорость, ширина панели, скругления, тень и плавное раскрытие. «Панель»: видимость сеансов, времени, токенов и лимитов, число сеансов, состояние подключения обычного чата Claude и закрытие по внешнему клику. Для каждого источника доступны режимы «Всегда показывать», «Скрывать без связи», «Скрывать без активных задач» и «Всегда скрывать». Значения сохраняются локально и применяются без перезапуска. Звук по умолчанию выключен. Уменьшение движения в macOS отключает анимацию независимо от переключателей приложения.

## Демонстрация и интерфейс

В настройках уведомлений нажмите «Демо». Сценарий показывает раскрытие и сворачивание, ожидание действия, завершение, ошибку и остаток лимита; в конце — 12 искусственных чатов с прокруткой. После демо восстанавливаются реальные данные.

Сеансы показаны отдельными карточками. Подсказки при наведении объясняют иконки токенов; длинный список имеет постоянно видимую полосу прокрутки. Логотип бренда подпрыгивает при ожидании действия.

## Диагностика

В настройках → «Основные» нажмите «Открыть логи». Журналы находятся в `~/Library/Logs/AgentIsland`, хранятся 7 дней и ограничены 2 МБ в сутки на журнал. Записываются ID сеансов, изменения статусов, события hooks и результат переключения окна; тексты переписки, названия проектов и ключи не записываются.

Объединение лимитов одного бренда (`99%/50% 5ч/7д`) включается и отключается в настройках панели. Каждый процент имеет собственный цвет. Уведомление об остатке 10% и ниже отображается красным.
